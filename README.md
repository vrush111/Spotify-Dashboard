🔹 Project Title

Spotify Analytics Dashboard | Power BI

🔹Short Description / Purpose

An interactive Power BI dashboard designed to analyze Spotify music data and uncover insights into streaming trends, artist popularity, song characteristics, and platform comparisons. This dashboard enables users to make data-driven decisions by visually exploring key performance metrics.

🔹Tech Stack

Power BI Desktop – Data visualization and dashboard creation

Power Query – Data cleaning and transformation

DAX (Data Analysis Expressions) – Calculated measures and KPIs

Data Modeling – Relationship building for efficient analysis

🔹Data Source

Spotify dataset containing information on songs, artists, streaming counts, energy, danceability, and release years.

The dataset was structured and transformed to support analytical reporting.

Features / Highlights
🔹 Business Problem

Music platforms generate massive amounts of data, but extracting meaningful insights about song performance, artist impact, and listener preferences can be challenging without effective visualization.

🔹 Goal of the Dashboard

To create a visually engaging and analytical dashboard that helps users:

Identify the most streamed songs

Analyze artist impact

Track music trends over time

Compare platform performance

Understand audio features like energy and danceability

🔹 Key Visuals

Most Streamed Songs (Bar Chart)

Artist Impact Analysis

Average Energy vs Danceability Trend

Platform Comparison

KPI Cards (Total Songs, Total Artists, Avg Danceability)

🔹 Business Impact & Insights

Helps stakeholders quickly identify top-performing artists and tracks

Supports strategic decisions using streaming patterns

Enhances understanding of listener behavior

Provides a centralized view of critical music metrics
